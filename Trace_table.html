1.1 Binary Units & Storage Capacities
📅 Topic 1 — Mock Checklist 🏷️ Paper 1: Data Representation
💡 Core Concept: Why Computers Use Binary
Computers are built from billions of microscopic switches called transistors. A transistor only has two reliable physical states: ON (1 / High Voltage) and OFF (0 / Low Voltage). Using just two states prevents electrical interference from corrupting data.

1. The Hierarchy of Data Units

  • Bit (b): The smallest atomic unit of data in a computer — a single 0 or 1.
  • Nibble: A group of 4 bits (half a byte). Crucial because 1 Nibble equals exactly 1 Hexadecimal digit.
  • Byte (B): A group of 8 bits. Enough to store one standard ASCII character (e.g., 'A' = 01000001).

⚠️ Exam Trap: Bits (b) vs Bytes (B)
Broadband speeds are measured in Megabits per second (Mbps), whereas file sizes are measured in Megabytes (MB). Always divide bits by 8 to convert to Bytes!
1.2 Binary, Denary & Hexadecimal Conversions
📅 Topic 2 — Mock Checklist 🏷️ Paper 1: Number Systems

1. Why Do Programmers Use Hexadecimal (Base 16)?

Computers do not run on hexadecimal—they only understand binary. Hexadecimal (digits 0–9 and A–F where A=10, B=11, C=12, D=13, E=14, F=15) is used by humans because:

  • Compactness: 1 Hex digit represents 4 binary bits. An 8-bit byte takes just 2 Hex characters (e.g., 11111111₂ = FF₁₆).
  • Fewer Human Errors: Easier to read and type without miscounting long strings of 1s and 0s (used in MAC addresses, IPv6, and HTML color codes like #FF5733).

3. Binary ↔ Hexadecimal (The Nibble Split Rule)

⚡ Fast Method: Convert 11011011₂ to Hex
1. Split the byte into two 4-bit nibbles: 1101 and 1011
2. Apply 8 - 4 - 2 - 1 to each nibble:
   • Left nibble: 8 + 4 + 0 + 1 = 13 → Letter D
   • Right nibble: 8 + 0 + 2 + 1 = 11 → Letter B
3. Combine: DB₁₆

1.3 Binary Arithmetic, Overflow & Shifts
📅 Topic 3 — Mock Checklist 🏷️ Paper 1: Data Representation

1. The Four Rules of Binary Addition

OperationResultCarryExplanation
0 + 000Zero plus zero equals zero
0 + 1 or 1 + 010Equals one
1 + 101Equals 2 in denary (10₂) → write 0, carry 1
1 + 1 + 111Equals 3 in denary (11₂) → write 1, carry 1
🚨 Overflow Error (9th Bit Carry)
An 8-bit register can only store values from 0 to 255. If a binary addition produces a carry out of the 8th bit (requiring a 9th bit), an Overflow Error occurs. The CPU drops the 9th bit, causing the stored result to be completely inaccurate.

2. Binary Shifts (Multiplication & Division)

  • Logical Left Shift: Moves all bits to the left and fills empty spaces on the right with 0s.
    • Shift Left by 1 = Multiply by 2 (× 2¹)
    • Shift Left by 2 = Multiply by 4 (× 2²)
    • Shift Left by 3 = Multiply by 8 (× 2³)
  • Logical Right Shift: Moves all bits to the right and fills empty spaces on the left with 0s.
    • Shift Right by 1 = Divide by 2 (÷ 2¹) — note: rightmost bits shifted off are lost, causing loss of precision.
1.4 Representation of Images & Text (ASCII)
📅 Topic 7 — Mock Checklist 🏷️ Paper 1: Data Representation

1. Character Sets: ASCII vs. Unicode

  • Character Set: A defined list of characters recognized by a computer, where each character has a unique binary code.
  • Standard ASCII (7-bit): Represents $2^7 = 128$ characters (English alphabet A–Z, a–z, numbers 0–9, punctuation, control codes). Extended ASCII uses 8 bits ($256$ characters).
  • Unicode (16-bit / 32-bit): Created because 8-bit ASCII cannot represent non-Latin alphabets (Arabic, Mandarin, Yoruba, Cyrillic) or emojis. Unicode supports over 140,000 characters, at the cost of larger file sizes per character.

2. Bitmap Images & File Size Formula

  • Pixel (Picture Element): The smallest single block of color in a bitmap image.
  • Resolution: Dimensions of the image in pixels (Width × Height).
  • Color Depth: Number of bits used to store the color of each pixel. A color depth of $n$ bits allows $2^n$ colors (e.g., 8-bit color depth = $2^8 = 256$ colors; 24-bit True Color = $16.7 ext{ million}$ colors).
  • Metadata: Extra data stored inside the image file so the computer knows how to render it (width, height, color depth, camera GPS, date taken).
📐 Essential GCSE Image File Size Formula
Image File Size (in bits) = Width (px) × Height (px) × Color Depth (bits)
To convert to Bytes: Divide the total bits by 8.
2.1 System Architecture: Von Neumann & The CPU
📅 Topic 5 — Mock Checklist 🏷️ Paper 1: Computer Systems

Von Neumann Architecture is the design used by almost all modern computers, where both program instructions and data are stored together in the same main memory (RAM).

Figure 2.1: Von Neumann CPU Registers, ALU, Control Unit, and System Buses connected to RAM.

1. The Four Essential CPU Registers

RegisterFull NameExact Exam Role
PCProgram CounterHolds the memory address of the next instruction to be fetched. Increments by 1 after each fetch.
MARMemory Address RegisterHolds the memory address in RAM currently being read from or written to.
MDRMemory Data RegisterHolds the actual instruction or data fetched from RAM (or waiting to be written to RAM).
ACCAccumulatorTemporarily stores the intermediate and final results of calculations performed by the ALU.

2. The Fetch–Decode–Execute (FDE) Cycle

  1. Fetch: The address in the PC is copied into the MAR. The CPU sends a read signal along the address bus to RAM. The instruction at that address travels back along the data bus into the MDR. The PC increments by 1.
  2. Decode: The Control Unit (CU) inspects the instruction in the MDR and decodes what operation needs to be performed.
  3. Execute: The instruction is carried out (e.g., loading data from RAM, performing math in the ALU, or storing a result in the ACC).

2. Embedded Systems

🔧 Definition: Embedded System
An embedded system is a dedicated computer system built into a larger mechanical or electrical device to perform one specific function (often in real time).
  • Examples: Washing machine controller, microwave timer, car engine management unit (ECU), traffic light controller, smart thermostat, pacemaker.
  • Characteristics: Firmware stored in ROM (cannot be easily changed by the user), low power consumption, small physical size, cheap to mass-produce, and very reliable.
3.1 Primary Memory (RAM/ROM) & Secondary Storage
📅 Topic 6 — Mock Checklist 🏷️ Paper 1: Memory & Storage

VolatilityVolatile: Loses all contents immediately when power is turned off.Non-Volatile: Retains data permanently even without power.

Virtual Memory: When RAM becomes completely full, the OS temporarily moves inactive pages of data from RAM onto a reserved section of the secondary storage drive (HDD/SSD). Because secondary storage is much slower than RAM, excessive swapping ("disk thrashing") slows the PC down.

3.2 Utility Software (System Maintenance)
📅 Topic 6 — Mock Checklist 🏷️ Paper 1: Systems Software

Utility Software consists of specialized system programs designed to analyze, configure, optimize, and maintain a computer system:

  • Encryption Software: Scrambles sensitive files using a key so unauthorized users cannot read them if the device is stolen.
  • Defragmentation Software: Over time, files on a magnetic HDD get split into scattered fragments across the disk. Defragmentation reorganizes files so all blocks of each file sit contiguously together, reducing read/write head movement and speeding up file access. (Note: Never needed on SSDs because SSDs have no moving read/write heads!)
  • Data Compression Software: Reduces file sizes so files use less storage space and transmit faster over networks:
    • Lossy Compression: Permanently removes redundant data (e.g., JPEG, MP3) — smaller file, slight quality drop.
    • Lossless Compression: Re-encodes patterns without losing a single bit (e.g., ZIP, PNG, FLAC) — original file can be 100% restored.

4.2 Encryption & Essential Network Protocols
📅 Topic 4 — Mock Checklist 🏷️ Paper 1: Network Security

1. Encryption (Plaintext → Ciphertext)

Encryption scrambles readable data (Plaintext) into unreadable code (Ciphertext) using a mathematical algorithm and a secret Key. If intercepted over public Wi-Fi, hackers cannot read the data without the decryption key.

  • Symmetric Encryption: Uses the exact same key to encrypt and decrypt. Very fast, but sharing the key securely is a challenge.
  • Asymmetric Encryption: Uses a Public Key (openly shared to encrypt messages) and a mathematically linked Private Key (kept strictly secret by the owner to decrypt). Powers HTTPS!

6.1 Mastering the GCSE 8-Marker Extended Question
📅 Topic 8 — Mock Checklist 🏷️ Paper 1: Legal, Ethical, Cultural & Environmental
🎯 The PEEL + Stakeholder Framework (Guaranteed Band 3: 7–8 Marks)
Examiners mark 8-mark questions using Levels of Response, not just bullet points. To reach the top band:
1. Cover at least 3 distinct perspectives (e.g., Legal, Ethical, Environmental, Privacy/Security).
2. Use PEEL in every paragraph: Point → Explain why → Example in context → Link back to the scenario.
3. Always give a balanced argument (benefits AND drawbacks) plus a brief concluding judgment.

Sample 8-Mark Question & Model Structure

"A school introduces facial recognition cameras at the canteen to replace RFID smartcards. Discuss the legal, ethical, and privacy issues associated with this technology." [8 marks]

  • Legal (Data Protection Act 2018 / UK GDPR): Biometric facial templates are special category personal data. The school must obtain explicit parental/student consent, store data securely with encryption, and delete records once students leave.
  • Privacy & Security: Centralizing biometric databases creates a high-value target for hackers. Unlike a stolen RFID card—which can simply be cancelled and reissued—a leaked facial biometric cannot be changed.
  • Ethical & Cultural Impact: Automated surveillance can create a culture of distrust among students, and facial recognition algorithms have historically shown higher error rates across diverse skin tones, risking unfair delays at lunch.
  • Conclusion: While facial recognition eliminates lost cards and speeds up queues, the school must implement strict encryption, opt-out alternatives, and GDPR compliance to outweigh the privacy risks.

Question 1: Binary Units

A student has 3 Nibbles and 2 Bytes of data. How many bits is this in total?

28 bits: (3 × 4 bits) + (2 × 8 bits) = 12 + 16 = 28 bits.

Question 2: Hexadecimal Conversion

Convert the binary byte 11100110₂ directly into Hexadecimal.

E6₁₆: Left nibble 1110 = 14 (E); Right nibble 0110 = 6.

Question 3: CPU Registers

Which register holds the memory address of the next instruction to be fetched from RAM?

Program Counter (PC).

Question 4: Network Protocols

Why is HTTPS essential when logging into an online banking portal over public Wi-Fi?

HTTPS encrypts data in transit using TLS/SSL, scrambling plaintext passwords into unreadable ciphertext so hackers intercepting packets cannot read them.
